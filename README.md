# FounderLink

## Overview

FounderLink is a full-stack microservices-based web application that connects startup founders, investors, and collaborators through a centralized platform. The application focuses on secure authentication, scalable service architecture, and efficient management of startup-related activities.

---

## Features

- User Registration and Login
- JWT-based Authentication and Authorization
- Role-based Access Control
- Microservices Architecture
- RESTful APIs
- Service Discovery using Eureka
- API Gateway
- Database Integration
- Responsive Frontend
- Docker Support

## How to Run

### Prerequisites

- Java 17 (or your version)
- Maven
- Node.js
- MySQL
- Docker (Optional)

### Steps

1. Clone the repository.

```
git clone <repository-url>
```

2. Configure the database.

3. Start Eureka Server.

4. Start API Gateway.

5. Run backend microservices.

6. Run the React frontend.
